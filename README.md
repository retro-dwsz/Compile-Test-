# Compile-Test
LLVM Clang VS MSVC

Dependencies:
- WinAPI (Windows 11/10) Download dari [sini](https://developer.microsoft.com/en-us/windows/downloads/windows-sdk/)
- fmt [install](https://github.com/fmtlib/fmt)
- LLVM Clang (v 20 atau lebih tinggi) [MinGW toolchain](https://github.com/mstorsjo/llvm-mingw/releases/tag/20250430) atau [Pure LLVM Clang](https://github.com/llvm/llvm-project/releases/tag/llvmorg-19.1.0)
- Microsoft MSVC a.k.a [Microsoft Visual Studio](https://visualstudio.microsoft.com/)
- OS: [Windows 10](https://www.microsoft.com/en-us/software-download/windows10) atau [Windows 11](https://www.microsoft.com/en-us/software-download/windows11) x86_64-bit (compile ulang jika kalian menggunakan procie ARM)
